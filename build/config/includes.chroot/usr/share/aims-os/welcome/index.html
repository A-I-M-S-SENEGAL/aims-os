AIMS OS · welcome

Bienvenue

AIMS OS 2.1, prêt pour vos cours.

Une base Debian 13 (Trixie) avec GNOME 48, la stack scientifique du tronc commun, et chaque filière à une commande. Aux couleurs d'AIMS Sénégal.

Ce qui est installé

La base, sur toute installation AIMS OS. Le détail vit dans les debian/control de chaque métapaquet, sur GitHub.

Mathématiques & science

NumPy, SciPy, SymPy, pandas, matplotlib, scikit-learn, Jupyter, R, TeX Live (français), conda (Miniforge).

Bureau

Firefox, LibreOffice en français, lecteur vidéo, codecs libres, Git, éditeurs de texte, terminal.

Système

Pare-feu activé, mises à jour de sécurité automatiques, locale française, fuseau de Dakar, cache de paquets du campus détecté tout seul.

Ajouter votre filière ou des outils

Une commande, depuis le terminal. Tout vient du dépôt AIMS OS et se met à jour avec le système.

shell 
# Big Data, NLP, vision, climat (Dask, NLTK, OpenCV, xarray, clients de bases)
sudo apt install aims-os-bigdata

# Sécurité et forensique (nmap, Wireshark, John, hashcat, Sleuth Kit, scapy)
sudo apt install aims-os-security

# Maths avancées (Maxima, Octave, R tidyverse, TeX Live complet, TeXstudio)
sudo apt install aims-os-math-extras

# Dev (Java, PHP, Podman, Docker, kubectl, Ansible, Rust, adb)
sudo apt install aims-os-desktop-dev

# Bureau étendu (GIMP, Inkscape, Chromium, Evolution, codecs non libres)
sudo apt install aims-os-desktop-extras

# Tout d'un coup
sudo apt install aims-os-everything

# Outils hors Debian : VS Code, RStudio, Node.js, DBeaver, Bun/Deno/uv
ls /usr/share/aims-os/install/    # puis : sudo /usr/share/aims-os/install/<outil>.sh

# PyTorch, JAX, SageMath… : un environnement conda
mamba create -n monenv python=3.13 pytorch jupyterlab

Sur un poste du labo AIMS

Les postes fixes du labo ont tout ce qui précède, plus VS Code, Google Chrome, Android Studio, GeoGebra, Scilab, QGIS, Zotero, Bruno, draw.io, Julia, Ghidra. Vous vous connectez avec votre identifiant AIMS ; vos fichiers restent sur votre poste.

Vos bases de données

Un serveur rien qu'à vous, sans droits particuliers : aims-db start postgres (ou mariadb, redis, mongo). aims-db status, aims-db stop.

Vos machines virtuelles

GNOME Boxes ou virt-manager pour faire tourner une machine cible (Kali, Metasploitable) sur votre poste, pas sur le réseau du campus.

Android

Android Studio avec un SDK partagé déjà en place. Au premier lancement, créez votre appareil virtuel (Pixel, 2 Go) ou branchez votre téléphone par USB.
